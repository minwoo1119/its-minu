## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/minwoo1119/its-minu.git

# Enter project directory
cd its-minu

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
